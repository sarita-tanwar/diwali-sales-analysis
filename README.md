# Diwali Sales Analysis | Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on analyzing Diwali sales data using Python to identify customer purchasing patterns, sales trends, and top-performing product categories.

The main objective is to explore the dataset, clean and prepare the data, and generate meaningful business insights through Exploratory Data Analysis (EDA).

Using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn, I performed data analysis and visualization to understand customer behavior based on gender, age group, occupation, marital status, state, and product category.

## 🎯 Project Objectives

- Analyze overall Diwali sales trends.
- Understand customer purchasing behavior.
- Identify high-performing customer segments.
- Explore sales distribution across different states.
- Identify popular product categories.
- Generate meaningful insights to support business decisions.

## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Key Analysis Performed

- Data loading and inspection.
- Data cleaning and handling missing values.
- Exploratory Data Analysis (EDA).
- Customer demographic analysis.
- State-wise sales analysis.
- Product category analysis.
- Data visualization using charts and graphs.

## 📊 Key Insights

- Identified customer segments contributing to sales.
- Analyzed purchasing patterns across different age groups and genders.
- Explored state-wise customer purchasing trends.
- Identified popular product categories.
- Generated insights that can help businesses improve marketing and sales strategies.

## 💡 Business Recommendations

The analysis can help businesses understand customer preferences, identify valuable customer segments, improve product planning, and develop more effective marketing strategies.
